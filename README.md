# Guest Score Evaluation App
Guest Score Evaluation App is a system designed to calculate and maintain a “Guest Score” for hotel guests based on:

- Past behavior and stay history
- Adherence to hotel policies
- Reported damages or incidents

The app provides a reliable scoring mechanism to help hotels assess the risk associated with hosting a particular guest. It can be used to improve decision-making, enhance safety, and reduce operational risks in hospitality management.

## Key Features:
- Track and store guest history
- Automatically calculate guest scores
- Generate reports for hotel staff
- Support for policy-based risk assessment
- Optional integration with hotel management systems

## Tech Stack (example):
- **Backend:** Golang / Node.js
- **Frontend:** ReactJS / VueJS
- **Database:** PostgreSQL / MySQL
- **Deployment:** Docker, Kubernetes, Helm


## Local Setup
If you want to work locally using your own IDE, you can clone this repo and push changes. Pushed changes will also be reflected.

The only requirement is having Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

Follow these steps:

```sh
# Step 1: Clone the repository using the project's Git URL.
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory.
cd <YOUR_PROJECT_NAME>

# Step 3: Install the necessary dependencies.
npm i

# Step 4: Start the development server with auto-reloading and an instant preview.
npm run dev
```
